# GFG Bennett — Cosmic Heist

## Concept
An outlaw-tech launch experience for the GeeksForGeeks Student Chapter at Bennett University. The Crew is stealing the future with a one-day hackathon, workshop, mentorship, tracks, swag, and a cosmic bounty board. The event runs **28 September 2026, 9:00 AM–3:00 PM local time**.

## Stack
Framework-free HTML, CSS, and JavaScript. Three.js, GSAP, ScrollTrigger, and Google Fonts load from CDNs. GitHub Pages-ready with no build step.

```text
index.html
css/style.css
js/main.js
js/three-scene.js
js/cursor.js
js/registration.js
assets/images/moai-hull.jpg
README.md
.gitignore
```

## Run locally
Open `index.html` directly, or run `npx serve .` and visit the URL it prints.

Live demo: `https://adityasharmacodeshere-web.github.io/Marvel-Head_GFG/`
